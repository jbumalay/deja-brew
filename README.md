# Deja Brew

A specialty coffee concept landing page — a sample portfolio project.

## Overview

Deja Brew is a fictional café brand built as a clean, responsive static landing page. The site features a hero section, signature menu, brand story, manifesto, café experience collage, location, and newsletter signup.

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS v4
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

The development server runs on `http://localhost:8443` by default.

## Project Structure

```
src/
├── components/   # UI components (Navbar, Hero, Footer, etc.)
├── data/         # Static content (menu, photos, place info, nav)
├── App.tsx       # App orchestrator
├── main.tsx      # React entrypoint
└── index.css     # Global styles + Tailwind v4
```

## Available Scripts

- `npm run dev` — Start development server
- `npm run build` — Build for production
- `npm run preview` — Preview production build
- `npm run format` — Format code with oxfmt
